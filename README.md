# auto-archdiagram

> 把一段结构化描述（或直接粘贴一段中文建设说明）变成可打印、可逐项编辑的分层架构逻辑图。单个 HTML 文件、零依赖、完全离线。

**v0.1.0** · MIT 许可 · 100% 离线 · 零依赖 · 无需构建 · 简体中文界面

为方案、可研中的架构章节而做：白底深字、可黑白打印，图中每一处文字仍可编辑。支持分层堆叠、左／右／双侧横向支撑带、底部流程带，以及房顶梯形或纯文字的总体说明。

---

## 快速开始

```bash
git clone https://github.com/cs445194891/auto-archdiagram.git
cd auto-archdiagram
open auto-archdiagram.html        # macOS
# Windows: start auto-archdiagram.html
# Linux:   xdg-open auto-archdiagram.html
```

也可以只下载 `auto-archdiagram.html` 后双击打开。无需服务端、无需安装、无需账号、无需联网——整个工具就是这一个文件。

上手三步：左侧点「载入示例」，或粘贴一段分层架构说明后点「解析」；解析结果进入可编辑核对表，逐项确认后图纸自动同步；在图纸上点选任意文字可改内容、字号、对齐，工具条「自检」会检查溢出、留白与底边对齐，最后按需导出。

> 界面为简体中文，导出文件默认使用中文文件名。粘贴解析器针对中文建设说明调优；其余标签可用任意语言填写。

## 主要特性

- **真正离线。** 无 CDN、无外部字体与脚本、无遥测、无网络请求；连 ZIP 与 OOXML 包的生成都内联实现。
- **三种输入路径。** 结构化表单；对中文说明做规则解析与自动分段；带逐字段溯源的可编辑核对表。未识别段落单列展示，不静默生成、不补全未载明内容。
- **图纸上点选编辑。** 选中任意文字即可改内容、字号与对齐；连续调整不会丢失选中，可只恢复当前文字块或恢复全部。
- **版式可控。** 最多 5 层；横向支撑带可选左侧／右侧／双侧；底部流程带可选；总体说明可选房顶梯形或纯文字；5 套浅色主题均为白底深字，可黑白打印。
- **逐层高度（64–400 px）** 可自定义，内容装不下时自动压缩至最低 0.75 倍。支撑带更高时拉宽层间距而非拉伸层框，底边仍严格对齐。
- **框内纵向均匀分散。** 每个框的内容块按「上下等留白 + 块间距均分」重排，框底不再出现大片空白。
- **逐项编辑。** 组件卡、功能项、支撑带各组条目、流程步骤均可单独增、删、改；删除后已展开的分组保持展开。
- **内置自检**，导出前检查文字溢出、框内均衡、层高实算、支撑带对齐与深色填充。

## 数据模型

可通过「导出模型 JSON」／「导入模型 JSON」读写整张图，也可导出溯源表 CSV。

```js
// 结构示意，非字面 JSON
{
  canvasW, introStyle, roofAngle, roofH, theme,
  title, subtitle, note, captions: [文字, 文字],
  layers: [{ name, place, dashed, h, cards: [{ t, s }], chips: [文字], lines: [文字] }],
  cross: {
    side: 'none' | 'left' | 'right' | 'both',
    right: { name, sub1, sub2, capLabel, caps: [], withLabel, withItems: [], sysLabel, system: [] },
    left:  { /* 结构相同，内容独立 */ }
  },
  flow: { enabled, arrows, title, right, foot, steps: [{ name, lines: [文字] }] }
}
```

上限：5 层 · 每层 4 张组件卡与 9 个功能项 · 支撑带每组 8 项 · 6 个流程步骤 · 每步 3 行说明 · 画布宽 600–1200 px。

## 导出格式

| 输出 | 导出后是否可编辑 | 说明 |
| --- | --- | --- |
| `SVG` | 矢量编辑器中可编辑；新版 Office 可用「转换为形状」 | 白底，适配打印 |
| `PNG` | 否 | 2 倍分辨率 |
| `Office 友好 SVG` | 是，新版 PowerPoint／WPS | 分组变换已展开、marker 改为显式三角形、移除 `<defs>` |
| `PPTX` | 是，原生 PowerPoint 形状 | 浏览器内生成最小 OOXML／ZIP 包；框、文字、连线均为独立形状 |
| `draw.io`（`.drawio`） | 是，diagrams.net | 可另存为 `.vsdx` 供 Visio 使用 |
| `可编辑网页` | 是，独立单文件 | 自带内联编辑器；不再提供 PPTX／Office SVG／draw.io 按钮 |
| `CSV` / `JSON` | 数据，非图形 | 溯源表／完整模型往返 |
| 打印 | — | 只输出图纸并复位缩放 |

### 在 Office 与 Visio 中继续编辑

依据微软与 WPS 官方文档，PowerPoint 2019／2021／2024／Microsoft 365（Windows）及 WPS 演示 12.1.0.28022+ 支持把插入的 SVG「转换为形状」，逐个编辑。PowerPoint 2016 及更早、Mac／移动端只能整体改色，请改用 PNG 或原生 PPTX 导出。Visio 插入 SVG 通常仍是图片，请导出 draw.io 文件后另存 `.vsdx`。

**核实状态**：上述结论来自厂商文档，**并非**在开发机上的真实 Office／WPS／Visio 中打开验证；PPTX 的母版／版式／主题为最小实现。正式使用前请在自己的 Office／WPS／Visio 中打开导出文件确认一次。

## 隐私

粘贴的文本仅存内存。只有显式点击「保存模板」才会写入浏览器 `localStorage`。无统计上报、无上传、无任何外部资源。

## 已知限制（v0.1.0）

- 界面与内置示例为简体中文；示例描述的是通用视频会议系统，不含真实单位名称或项目数据。
- 粘贴解析为规则实现，适配「分层描述 + 顿号并列 + 流程动词」式中文建设说明；其他文体需手工整理。
- 自定义层高低于该层压缩后的最小高度时，会被撑到最小高度并给出警告；仅 1 层且启用支撑带时，为保持底边对齐仍会撑高该层。
- `.drawio` 不是旧版 Visio 的 `.vdx`；请用 diagrams.net →「导出为 → VSDX」。
- 隐藏流程箭头后，步骤卡之间 10 px 间隙保留为空白，卡片不会变宽。
- 导出文件默认使用中文文件名。
- 已在无头 Chrome 中验证（几何、XML、导出包、合成交互）；其他现代浏览器只用标准 SVG／Canvas／Blob API，但**未实测**。
